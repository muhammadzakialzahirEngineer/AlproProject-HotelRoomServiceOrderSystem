 🏨 Hotel Semtoro Food Ordering System

Aplikasi console berbasis C++ untuk mengelola pesanan makanan dan minuman
tamu hotel. Proyek ini dibuat sebagai tugas Algoritma dan Pemrograman (AlproProject).

## Fitur
- Tambah pesanan (makanan/minuman) untuk tamu baru atau tamu yang sudah ada
- Tampilkan seluruh pesanan, dikelompokkan per pemesan dan nomor kamar
- Cari pesanan berdasarkan nama pemesan
- Hapus pesanan: semua, satu pemesan, atau beberapa pemesan sekaligus
- Perhitungan total harga otomatis
- Data tersimpan permanen di `orders.txt`

## Teknologi & Konsep
- C++ (STL: vector, set, fstream)
- Doubly Linked List untuk menyimpan data pesanan
- File handling (baca/tulis file teks)
